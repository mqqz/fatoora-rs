# Getting Started

## Prerequisites
- Rust (stable) and Cargo
- `libxml2` development package
- Optional: `uv` for Python bindings development

If `libxml2` is missing, install it via your system package manager and re-run `cargo check`.

## Install the Rust crate
```bash
cargo add fatoora-core
```

## Install the CLI
```bash
cargo install fatoora-rs-cli
```

## Verify the workspace
```bash
cargo check
```

See also: [Configuration Reference](../reference/configuration.md)
