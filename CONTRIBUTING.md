# Contributing to fatoority

Bug reports, documentation fixes, tests, and code improvements are welcome.
For a large change, open an issue to discuss the approach first.

The [contributing guide](docs/contributing.md) is the single source for checkout
setup, checks, documentation previews and pull requests. You can also read it
on the [documentation site](https://docs.fatoority.com/contributing/).

Follow the [code of conduct](CODE_OF_CONDUCT.md). Original contributions are
licensed under both MIT and Apache-2.0; identify third-party material and retain
its licenses and notices. Report security issues through [SECURITY.md](SECURITY.md).
